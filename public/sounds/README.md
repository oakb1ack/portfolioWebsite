# Section transition sound

`chapter-whoosh.mp3` is an original, 420ms synthesized cue made for this
portfolio. It combines softly filtered noise, a descending low sine tone,
and a squared-sine volume envelope. No third-party recordings are used.

It plays quietly only while background music is enabled. Pausing music mutes
transition effects too. It does not preload or play on page load, and a failed
play request never blocks navigation. Reduced-motion navigation skips the cue.

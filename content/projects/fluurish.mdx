## Overview

Fluurish is a financial application built around budgeting, learning, progression, and community features. My work centered on the backend: turning the product's feature set into a coherent API and a reproducible set of services.

The project paired a React Native client with a FastAPI service and PostgreSQL database. Docker Compose kept the application and its database configured as one portable development environment.

## What I built

I architected the FastAPI backend that supported the application's core financial features. Its REST API covered:

- authentication;
- budgeting;
- quizzes and financial education;
- user progression; and
- community features.

Keeping these responsibilities behind a defined API gave the client a consistent interface while keeping persistence and business logic on the server.

## AI-assisted education

I integrated the Gemini API to support AI-assisted financial education and personalized interactions. The model integration complemented the application's structured features rather than replacing its underlying user and progression data.

## Reproducible services

FastAPI and PostgreSQL ran together through Docker Compose. Treating both as configured services made it easier to reproduce the backend environment without relying on a separately prepared local database.

## Outcome

Fluurish won its hackathon. The result demonstrated a broad product surface—financial tooling, education, personalization, and community—supported by a backend that could be run as a consistent group of containerized services.

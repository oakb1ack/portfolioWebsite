## Overview

My home lab is a containerized Linux platform that brings networking, monitoring, databases, and developer tooling into one self-hosted environment. It is both useful infrastructure and a place to practice operating the kinds of services that application code depends on.

The platform includes PostgreSQL and Redis data services, Forgejo for development workflows, and a Prometheus and Grafana observability stack.

## Service access

Caddy provides reverse proxying for the hosted services. Tailscale supplies the private network path used for secure remote access.

This arrangement keeps service routing and remote connectivity as explicit infrastructure concerns. Individual services can remain containerized while Caddy and Tailscale provide a consistent way to reach them.

## Monitoring the platform

Prometheus collects infrastructure and container telemetry, while Grafana presents that data for inspection. Monitoring is part of the platform itself rather than a separate exercise added only when something fails.

That visibility makes the lab a better environment for learning how services behave over time and how an operator can investigate them.

## Why it matters

The home lab connects several layers of systems work: Linux administration, container deployment, private networking, proxy configuration, persistence, and observability. Running them together exposes the operational boundaries between services in a way that isolated development environments do not.

It also provides a durable place to host developer and data services while continuing to develop practical infrastructure experience.
